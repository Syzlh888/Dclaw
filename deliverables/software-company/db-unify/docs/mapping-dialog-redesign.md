## 关键规则

| 行为 | 说明 |
|---|---|
| 选源连接 → 联动源 schema | 已有 |
| 选源 schema → 加载源表列表 + 源 columns | 已有 |
| 选目标连接 → 联动目标 schema | 已有 |
| 选目标 schema → 加载目标表列表（用于检测存在） | 已有 |
| 源表前 ☑ 多选 + 全选 + 搜索 | **新加**（左侧 Checkbox 列） |
| 目标表默认 = 源表同名 | **新加**（如果同名目标表已存在 ✓ 标识） |
| 目标表不存在 | 加 ❓ / 灰底提示 |
| 目标表下拉可改 | 下拉选择 target.x 或 input 自定义 |
| 增量字段下拉 | 拉源表 columns 列表（从 connectionStore.metadata 缓存） |
| 字段映射按钮 | 点开 TableMappingEditor |
| 自定义 SQL | 选「选中表 / 自定义 SQL」RadioGroup（已有）|
| 创建 | 批量 POST sync_table-mapping |

## 实现要点

1. **删除 Stepper**（不要三步步骤）
2. **一次性展示**所有内容
3. **数据流**：
   ```
   useEffect 选源连接 → 加载 schema
   useEffect 选源 schema → 加载 sourceTables
   useEffect 选目标连接 → 加载 schema
   useEffect 选目标 schema → 加载 targetTables（用于检测存在）
   useEffect 选中源表 → 加载每张表 columns（增量字段下拉数据）
   ```
4. **目标表自动同步**：选中 source 表时默认 target = 同名
5. **目标表存在标识**：targetTables Map 里查到 → ✓ 绿点；没查到 → ⚠️ 黄点
6. **全选按钮**：勾选所有源表
7. **搜索框**：本地过滤树
